# Liberty Ops 250

A commemorative operations dashboard with military-inspired instrument panels and patriotic accents.

## Compatible installation

Use a complete All Themes package, or a stock Suite package containing this
theme's registrations. On a compatible All Themes installation, copy the
complete `libertyops250` folder under
`SCRIPTS:/rfsuite/widgets/dashboard/themes/`, then restart the Suite Lua session
or radio. Select **Liberty Ops 250** in **System → Settings → Dashboard → Themes**;
configure it in **Dashboard → Settings → Liberty Ops 250**. Both choices require at least
784 × 294 available pixels. Full-screen rendering is 800 × 480.

All Themes uses `system/libertyops250` and `dashboard.libertyops250`. Settings save
on the radio; they do not write flight-controller EEPROM. Preserve user
settings when updating. [Full theme guide](../../../../../../docs/dashboard/libertyops250.md)
and [submission standard](../../../../../../docs/theme-submissions.md).

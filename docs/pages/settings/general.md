# General

Settings -> General.

## Where to find it

*System* → *Settings* → *General*

Always available offline without an active flight controller connection. Read-only while the model is armed.

## Settings

| Setting | What it does |
| --- | --- |
| *None* | This page provides status or interactive operations without persistent settings. |


## Notes

- With **Follow dashboard theme** enabled, Theme Bridge loads Bastion's palette
  from `widgets/dashboard/themes/bastion`. Older installs with the `aegis`
  folder remain supported; saved `system/aegis` selections continue to work.
- Changes are written to the flight controller EEPROM upon Save.
